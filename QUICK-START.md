## 🎯 En 3 commandes

```bash
# 1. Installer les dépendances
npm install

# 2. Vérifier que tout fonctionne
npm run doctor

# 3. Lancer l'application
npm start
```

## 📱 Tester sur téléphone

1. **Scanner le QR code** affiché dans le terminal
2. **Utiliser l'app Expo Go** (gratuite sur Play Store/App Store)
3. **L'app se lance automatiquement** sur votre téléphone
