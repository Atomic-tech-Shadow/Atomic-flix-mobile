# Changelog - ATOMIC FLIX

## [2.6.2] - 2025-07-22

### Added
- Politique de confidentialité considérablement renforcée
- Nouvelles sections légales : non-hébergement, DMCA, responsabilité utilisateur
- Disclaimers complets sur le rôle d'agrégateur de liens
- Documentation spécialisée pour réponse aux rejets stores (Uptodown)
- Support multilingue amélioré pour les badges de genres longs

### Changed
- Clarification du fonctionnement technique (interface uniquement)
- Mise à jour des conditions d'utilisation avec nouvelles sections légales
- Version mise à jour à 2.6.2 dans tous les fichiers de configuration
- Renforcement de la transparence sur la nature non-hébergeuse de l'app

### Fixed
- Affichage optimisé des genres longs avec flexWrap
- Support du texte sur plusieurs lignes pour badges multilingues
- Alignement cohérent des éléments d'interface

### Security
- Aucune collecte de données personnelles non nécessaires
- Stockage local uniquement pour respect vie privée
- APIs publiques utilisées de manière transparente

Initial release of Atomic Flix
