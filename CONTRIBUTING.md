# Contributing to Atomic Flix

Thank you for your interest in contributing to Atomic Flix!

## Development Setup

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/atomic-flix-mobile.git
   cd atomic-flix-mobile
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start development server:
   ```bash
   npm start
   ```

## Code Style

- Use TypeScript for all new code
- Follow existing code formatting
- Add proper error handling
- Write descriptive variable names
- Include comments for complex logic

## Submitting Changes

1. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. Make your changes
3. Test your changes thoroughly
4. Commit with descriptive messages:
   ```bash
   git commit -m "feat: add new search functionality"
   ```

5. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```

6. Create a Pull Request

## Issues

- Use GitHub Issues for bug reports and feature requests
- Include steps to reproduce for bugs
- Provide device and OS information when relevant
