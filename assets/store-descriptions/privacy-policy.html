⚛️ Politique de Confidentialité - Atomic Flix

Dernière mise à jour : 22 juillet 2025

1. Informations Collectées

Atomic Flix collecte uniquement les données essentielles au fonctionnement de l'application :

  • Préférences utilisateur : Langue sélectionnée, épisodes visionnés, favoris
  • Données techniques : Informations d'appareil pour optimisation (modèle, version Android)
  • Historique de visionnage : Stocké localement pour améliorer l'expérience

2. Utilisation des Données

Les données collectées servent exclusivement à :

  • Personnaliser votre expérience de visionnage
  • Sauvegarder vos préférences et progression
  • Optimiser les performances de l'application
  • Améliorer la qualité du service

3. Disclaimer Légal - Non-Hébergement

🚨 ATOMIC FLIX N'HÉBERGE AUCUN CONTENU VIDÉO OU MANGA.

Cette application fonctionne exclusivement comme un agrégateur de liens publiquement disponibles sur Internet :

  • Aucun fichier média stocké : Nous ne stockons, n'hébergeons, ni ne distribuons aucun fichier multimédia
  • Interface utilisateur uniquement : L'app sert d'interface pour accéder à des contenus hébergés par des plateformes tierces
  • APIs publiques : Utilisation d'APIs publiques pour indexer le contenu disponible
  • Liens externes : Tous les liens proviennent de sources externes tierces

4. Droits d'Auteur et Responsabilité

Respect de la propriété intellectuelle :

  • Responsabilité utilisateur : L'utilisateur est seul responsable de l'utilisation qu'il fait des liens fournis
  • Légalité locale : Il appartient à chaque utilisateur de s'assurer de la légalité du contenu dans sa juridiction
  • Réclamations DMCA : Pour toute réclamation de droit d'auteur, contactez directement les plateformes d'hébergement
  • Limitation de responsabilité : ATOMIC FLIX ne peut pas retirer un contenu qu'elle n'héberge pas

5. Partage des Données

Atomic Flix ne vend ni ne partage vos données personnelles.

Connexions externes uniquement pour :

  • APIs publiques pour récupérer les informations de contenu
  • Services d'amélioration de performance (anonymisé)

6. Stockage et Sécurité

  • Stockage local : Préférences stockées sur votre appareil
  • Chiffrement : Données sensibles chiffrées
  • Accès : Aucun accès non autorisé à vos données

7. Vos Droits

Vous pouvez à tout moment :

  • Effacer vos données via les paramètres de l'app
  • Désinstaller l'application (suppression automatique)
  • Nous contacter pour questions : atomic.flix.support@gmail.com

Cette politique peut être mise à jour. Les changements majeurs seront notifiés dans l'application.
