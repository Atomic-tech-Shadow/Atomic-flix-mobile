# ATOMIC FLIX - Application Mobile Anime & Manga

## Description de l'Application

**ATOMIC FLIX** est une application mobile développée en React Native qui sert d'**interface utilisateur pour naviguer et découvrir des contenus anime et manga** disponibles publiquement sur Internet.

### ⚠️ DISCLAIMER IMPORTANT - NON-HÉBERGEMENT

**🚨 ATOMIC FLIX N'HÉBERGE AUCUN CONTENU VIDÉO OU MANGA.**

Cette application fonctionne **exclusivement comme un agrégateur de liens** publiquement disponibles sur Internet. Nous ne stockons, n'hébergeons, ni ne distribuons aucun fichier multimédia protégé par le droit d'auteur.

### Fonctionnement Technique

- **Interface utilisateur uniquement** : L'application sert d'interface pour accéder à des contenus hébergés par des plateformes tierces externes
- **APIs publiques** : Utilisation d'APIs publiques pour indexer le contenu disponible sur Internet
- **Aucun serveur d'hébergement** : Tous les liens proviennent de sources externes tierces
- **Aucun stockage local de médias** : Aucun fichier vidéo ou manga n'est stocké sur l'appareil ou nos serveurs

### Responsabilité et Légalité

- **Responsabilité utilisateur** : L'utilisateur est seul responsable de l'utilisation qu'il fait des liens fournis par l'application
- **Légalité locale** : Il appartient à chaque utilisateur de s'assurer de la légalité du contenu consulté dans sa juridiction
- **Respect des droits d'auteur** : Pour toute réclamation concernant le droit d'auteur, contactez directement les plateformes d'hébergement concernées
- **Limitation de responsabilité** : ATOMIC FLIX ne peut pas retirer un contenu qu'elle n'héberge pas
